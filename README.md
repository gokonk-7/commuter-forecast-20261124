One line of weather forecast (128 characters) for a city that does not exist — Grumbletown — written to make a bored commuter smile on the way to work. Entry for make.fun's "Charm the Commuter: Forecast a City That Isn't" bounty.

> In Grumbletown, drizzle till nine, then bright sun — the 8:12 bus is on time, and today the rain falls everywhere except on you.

The forecast keeps a broadcast-weather rhythm and bends it once: the drizzle clears, the bus is on time, and the rain itself plays favourites with the commuter reading it.

## Run it

```sh
node main.ts
```
